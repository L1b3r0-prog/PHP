## INDEXED ARRAYS

Syntax for declaring array:

```php
$my_array = array(item1, item2, item3);
```

```php
$my_array = [item1, item2, item3];
```

```php
$my_array[] = item1;
$my_array[] = item2;
$my_array[] = item3;
```

## MANIPULATING ARRAYS

- `array_push()` - adds one or more elements to the end of an array
  - it has variadic arguments – multiple elements can be added
  - returns the total number of the array elements
- `array_pop()` - removes the last element from the end of an array
  - returns the value of the removed array element
  - can be used with associative arrays as well
- `array_shift()` - removes the first element from the beginning of an array
  - returns the value of the removed array element
- `array_unshift()` - adds one or more elements to the beginning of an array
  - it has variadic arguments – multiple elements can be added

---

## MANIPULATING ARRAYS (continued)

```php
$indA1 = array("item1", "item2", "item3");

$num = array_push($indA3, 101, 102);

```

## MANIPULATING ARRAYS (continued)

- `array_splice()` - adds or removes array elements located anywhere in the array
  - renumbers the indexes in the array

```php
array_splice(array_name, start, number_to_delete, values_to_insert);
```

---

## MANIPULATING ARRAYS (continued)

- `unset()` - removes array elements and other variables
  - can remove multiple elements
  - do not renumber the next elements in the array
- `array_unique()` - removes duplicate elements from an array
  - returns a new array (with removed duplicate values), but does not renumber the indexes
- `array_values()` - can be used to renumber the indexed array elements
  - returns new array with renumbered indexes

## ASSOCIATIVE ARRAYS

- Associative arrays use strings as indexes (keys)
- The element's key are specified by using the array operator (`=>`)

```php
$my_array = array(key=>value, ...);
```

```php
$my_array = [key=>value, ...];
```

```php
$my_array[key1] = item1;
$my_array[key2] = item2; …
```

---

## ASSOCIATIVE ARRAYS (continued)

- If a new element is added to an associative array without specifying a key, the new element is assigned an index of 0 or the next available integer

```php
$states["NSW"] = "New South Wales";
$states["WA"] = "Western Australia";
$states[] = "Tasmania";
```

- An array can have starting index other than 0 without creating empty elements

```php
$states[100] = "New South Wales";
$states[] = "Western Australia";
$states[] = "Tasmania";
```

## ITERATING ARRAYS

- The **internal array pointer** refers to the currently selected element in an array
- A **foreach** statement allows looping through the elements of an array, but it does not change the position of the internal array pointer - for that purpose advanced foreach should be used

```php
foreach ($my_array as $key => $value)
{
    echo "The $key has $value";
}
```

## MANIPULATING ARRAYS (continued)

- `in_array()` - determines whether a given value exists in an array and returns a Boolean value of true/false
- `array_search()` - determines whether a given value exists in an array and returns the index/key of the first matching element or return false if the value does not exist
- `array_key_exists()` - determines whether a given index or key exists and returns TRUE or FALSE
- `array_keys()` - returns an indexed array that contains all the keys in an associative array
  - If a second argument is passed, the function will return the keys of the elements that match the specified value

*For home - check the functions: array_key_first(), array_key_last()*

## MANIPULATING ARRAYS (continued)

- `array_slice()` - returns a portion of an array

```php
array_slice(array_name, start, numbers_to_return);
```

```php
$ThreeStates = array_slice ($states, 2, 3);
foreach ($ThreeStates as $code => $state)
```

## SORTING ARRAYS

- `sort()` - sorts an indexed array in ascending order
- `rsort()` - sorts an indexed array in descending order
- `asort()` - sorts an associative array in ascending order
- `arsort()` - sorts an associative array in descending order
- `ksort()` - sorts an array by keys in ascending order
- `krsort()` - sorts an array by keys in descending order
- `natsort()` - sorts an array using a "natural order"

---

## COMBINING ARRAYS

- `array_combine()` - creates a new associative array by using the elements from one array as the keys and the elements from another array as the values
- array unpacking inside arrays - merging multiple arrays

```php
$array1 = [1, 2, 3];
$array2 = [4, 5, 6];
$combined = [...$array1, ...$array2];
```

## USING ARRAYS IN WEB FORMS

- PHP arrays can be used with HTML form input elements - enabling to store the form data in an array
- The name attribute of the input element needs to use array notation
  - the data from any element with the same value for the name attribute will be appended to an array with that name
  - the indexes of the array elements can be used if there is a need, otherwise the only need is to append an opening and closing square bracket (`[]`) to the value of the name attribute

```
name='req[]'  or  name='req[0]'  or  name='req[Q1]'
```

---

## USING ARRAYS IN WEB FORMS EXAMPLE

```php
<form action='ProcessForm.php' method='post' >
<p>Enter the first answer: <input type='text' name='answers[]' /></p>
<p>Enter the second answer:<input type='text' name='answers[]' /></p>
<p>Enter the third answer:<input type='text' name='answers[]' /></p>
```
